## Responsive and accessibility

The mint rail is 164 px (132 in narrow windows); below 700 DIP, its actions move to the header. Below 960 DIP, search occupies a full row with state/time filters underneath. Help and complete warning details open in owned, nonmodal windows with selectable, scrollable text and a visible close action. The main warning stays on one line so auxiliary content does not take over the list. Endpoint columns prioritize remote address, state and copy; those three columns stay frozen only when their minimum widths plus scrollbar allowance fit. Otherwise all columns can scroll. The default window fits every column; full values remain available through tooltips and copying. Mint row selection, restrained hover and dark-green keyboard focus match the rest of the controls. Search-empty uses a neutral magnifier and a clear reset action. Per-monitor DPI awareness is declared; simulated layout coverage is distinct from actual high-DPI hardware verification.
