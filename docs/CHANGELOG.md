# NetPeek 变更记录

## 0.1.1

- UI 异常正确返回失败退出码；GUI smoke 核验本轮身份、时间、有效快照和最终状态，零端点快照可正常通过。
- 差量更新连接与进程视图，无变化不重复通知；保留展开、选中和对象身份，复用状态画刷。
- 修复应用历史过期后重现无法绑定缓存图标；图标提取可重试、有界淘汰且不读取网络路径。
- 受限身份展示可延续交互，仍明确标为不确定归属且不留可信历史。历史截断提示保持到受影响窗口结束，扩展 UNC 路径正确保留绝对网络路径。
- 收紧侧栏、页头和行距；地址、状态、复制优先显示，统一薄荷绿选中与焦点状态，增加搜索清空入口。
- 根据当前屏幕工作区与 DPI 限制初始尺寸；小窗口收起侧栏并保留操作，说明和警告限高滚动。

验证、同机性能对比和未验证范围见 [0.1.1 验收报告](VALIDATION_0.1.1.md)。
