# NetPeek 变更记录

## 0.2.0

- 搜索与状态筛选作用于具体端点，增加当前快照／近 60 秒历史／全部时间范围；历史状态明确为最后观察状态。显示匹配端点数量，全机统计单独标明。
- 查询时定位首个结果，后续采样增量维护显示集合；保留仍在结果内的端点对象、选中项、滚动位置和用户展开选择。暂停时查询仍使用冻结画面。
- 增加本地端点、远端端点和含身份／观察时间的完整记录复制菜单，支持按钮、右键和 Shift+F10；UDP 与监听禁用远端复制。
- 数据说明与完整警告使用独立非模态窗口；主窗口警告保持单行，窄窗口搜索与筛选分行。详情固定列按最小宽度决定是否解除冻结。
- 增加筛选交集、历史转换、复制语义、真实 WPF 集合／选中／滚动保持及紧凑布局回归。历史版本验收记录保持原样；本版验收单独记录。
- 补齐系统剪贴板端到端与同机三场景性能回归；修复 PowerShell 7 报告时间解析，测试宿主对齐产品 DPI 清单并在窗口关闭前恢复剪贴板。

最终二进制、验证范围和性能证据见 [0.2.0 验收记录](VALIDATION_0.2.0.md)。

## 0.1.1

- UI 异常正确返回失败退出码；GUI smoke 核验本轮身份、时间、有效快照和最终状态，零端点快照可正常通过。
- 差量更新连接与进程视图，无变化不重复通知；保留展开、选中和对象身份，复用状态画刷。
- 修复应用历史过期后重现无法绑定缓存图标；图标提取可重试、有界淘汰且不读取网络路径。
- 受限身份展示可延续交互，仍明确标为不确定归属且不留可信历史。历史截断提示保持到受影响窗口结束，扩展 UNC 路径正确保留绝对网络路径。
- 收紧侧栏、页头和行距；地址、状态、复制优先显示，统一薄荷绿选中与焦点状态，增加搜索清空入口。
- 根据当前屏幕工作区与 DPI 限制初始尺寸；小窗口收起侧栏并保留操作，说明和警告限高滚动。

验证、同机性能对比和未验证范围见 [0.1.1 验收报告](VALIDATION_0.1.1.md)。
